DIO CRM Admin Screen/Menu Catalog v1.0

1. 설계 목적

DIO CRM의 관리자 기능은 Salesforce 관리자 기능을 그대로 복제하는 것이 아니라 다음 범위까지 내재화한다.

관리자가 직접 변경하는 영역

운영조직 / 사용자 / 권한 / 데이터 접근범위 / 화면 표시 / 공통코드 / 상태값 / 데이터 Import·Export / 감사로그 / ERP·API 연계상태 / Batch 운영

개발자가 관리하는 영역

DB Entity 생성 / DB Column 생성·변경 / 데이터 타입 변경 / Formula Engine / Lookup 관계 생성 / 임의 Business Logic / API 프로그램 변경

핵심 구조는 다음과 같다.

Admin UI → Admin API → Metadata/Config → CRM Web·Mobile → Business API Validation → Audit

화면만 Metadata를 적용하는 것이 아니라 API도 동일한 설정을 사용해야 한다.

38. 공통 관리자 권한

관리자라고 모두 같은 권한을 주지 않는다.

관리자 Role 주요 권한
SYSTEM_ADMIN 전체
CRM_ADMIN 사용자·조직·권한·화면·코드
DATA_ADMIN Import / Export / 대량처리
INTERFACE_ADMIN ERP/API/Batch
SECURITY_ADMIN 인증·접근·Audit
AUDITOR 모든 Audit 조회, 수정 불가

특히 AUDITOR는 조회 전용으로 한다.

39. 권한 계산 기준

최종 권한은 다음 구조로 계산한다.

최종 권한

= Role Permission
+ User Additional Permission
+ Data Scope
+ Record Share
- Security Restriction

Security Restriction이 최우선이다.

48. 목업 개발 완료 기준

Admin Mockup을 완료했다고 판단하려면 최소한 다음 Flow가 실제 화면에서 연결되어야 한다.

사용자 선택
 → Role 변경
 → 권한 Matrix 확인
 → Data Scope 지정

Lead 화면 선택
 → Field 표시/숨김 변경
 → 필수 여부 변경
 → Layout 변경

Lead Status
 → 코드 추가
 → 상태전이 설정

Excel Import
 → Mapping
 → Validation
 → Preview
 → 결과확인

ERP Interface
 → 오류조회
 → 오류상세
 → 재처리

Audit
 → 관리자 변경내용 확인

이 Flow가 동작하면 관리자 기능에 대한 UX/기능 검증을 먼저 수행하고 DB/API 구현 단계로 넘어갈 수 있다.

최종 구조

                     DIO CRM ADMIN
                           │
       ┌───────────────────┼───────────────────┐
       │                   │                   │
 사용자/조직              권한              화면 Metadata
       │                   │                   │
       └──────────────┬────┴──────────────┬────┘
                      │                   │
                  CRM Runtime         Code/Workflow
                      │                   │
                      └─────────┬─────────┘
                                │
                            Business API
                                │
             ┌──────────────────┼──────────────────┐
             │                  │                  │
           CRM DB             ERP/API            Audit

DIO CRM 관리자 기능은 별도의 CRM 플랫폼을 만드는 것이 아니라, 실제 CRM 운영에 반복적으로 발생하는 변경을 개발자 개입 없이 처리할 수 있도록 만드는 것이 최종 목표다.

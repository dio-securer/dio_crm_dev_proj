# extensions — 확장 구역

설정(`metadata/`)만으로는 표현할 수 없는 회사·국가 전용 동작을 두는 곳입니다. 확장 하나가 폴더 하나입니다(`extensions/<확장이름>/`).

## 무엇이 들어가나

- 특정 회사만 쓰는 계산, 외부 시스템 연결 규칙, 전용 검증처럼 공통 엔진에 넣으면 안 되는 코드.
- 지금은 비어 있습니다. 기존 코드는 옮기지 않았습니다.

## 누가 고치나

- 설정으로 해결되지 않는 요청이 승인됐을 때에만 AI 작업자가 확장을 만들거나 고칩니다.
- 공통으로 쓸 수 있는 기능이면 확장이 아니라 엔진에 넣어야 합니다.

## 적용되는 규칙

| 규칙 | 내용 |
| --- | --- |
| G02 | 확장 코드는 자기 폴더 안의 파일, `@dio-crm/contracts`, `@dio-crm/engine` 만 가져다 쓸 수 있습니다. 다른 확장, 화면 코드, 서버 코드, DB를 직접 잡으면 실패합니다. 코드 파일은 반드시 `extensions/<확장이름>/` 안에 둡니다. |
| G03 | 한 파일 300줄 상한. 이 구역에는 예외 폴더가 없습니다. |
| G07 | DB·네트워크를 직접 부를 수 없습니다. 엔진이 내주는 기능을 통해서만 부릅니다. |

회사별로 갈라지는 코드는 이 구역에만 둘 수 있습니다(G06 은 이 구역을 검사하지 않습니다).

규칙 전체 설명: [docs/framework/guard-rules.md](../docs/framework/guard-rules.md)

## 업무 규칙과 설계 가정

1. 리드 상태 선택은 화면의 임시값이며 상태 저장 API가 성공할 때 실제 상태가 변한다. 역행은 기존 customer.rules의 `LEAD.STATUS.REVERSE`와 사유를 요구한다. 목업에서는 관리자·지점장·본부장에게 이 권한을 부여하고 일반 영업에게 부여하지 않는다. `CONVERTED`는 전환 API만 만들 수 있다.
2. 기존 연결은 선택 거래처에 속한 동일 법인의 접근 가능한 연락처·기회만 허용한다. 연락처·기회 `SKIP`은 생성하지 않는다. 새 레코드 소유자는 기본적으로 리드 소유자를 승계하며, 다른 소유자 지정에는 관리 권한과 등록된 사용자가 필요하다.
3. 전환은 업무 행·참조·상태·이력·멱등 응답을 같은 저장소 트랜잭션으로 반영한다. 주입된 실패·잘못된 기존 연결·영속 저장 실패는 전체 복사본을 폐기한다. 성공 응답을 잃고 같은 멱등 키로 재시도해도 중복 생성하지 않는다.
4. 기존 코드의 keymanName은 전체 이름이다. 별도 성 분리는 관찰 근거가 없어 만들지 않는다. 키맨 특이사항, 병원 규모·의사/체어 수, 상세 제외 사유는 선택 입력으로 구현한다.
5. **CRM 이름과 ERP 이름을 분리한다.** 원본 인터페이스 카탈로그의 `cust_nm`은 IN 원천이다. 따라서 `account.erp.cust_nm`은 `erp_account_name`을 읽기 전용으로 표시하고, 별도 `account.crmName`이 기존 `accountName/account_name` 편집을 담당한다. 목업 ERP 승인은 요청 당시의 이름을 ERP명으로 고정한다. 요청 후 CRM 이름을 바꿔도 결과가 최신 CRM 이름을 덮어쓰지 않는다. 실제 ERP의 원천명 변경 정책은 별도 확인 대상이다.
6. ERP 코드·승인·거래여부·사용여부·ERP 상태 등 IN/DERIVED 필드는 일반 CRM 저장 API에서 거부한다. OUT 입력은 계속 편집할 수 있으며 ERP 요청 때 13개 필수 필드와 요청 snapshot을 검사한다. HIRA 수동 제외와 수동 수정 필드 보호를 적용한다.
7. 거래처 병합은 서로 다른 ERP 코드가 있으면 거부한다. 중복 대상에 ERP 요청 이력이 있으면 원본 요청/결과의 동일성을 보존하기 위해 자동 병합을 거부하고 검토가 필요함을 표시한다. 지원되는 병합은 연락처·기회·계약·주문·매출·활동·전환 참조와 이력을 한 번에 승계한다.
8. 관리대장 다중행 저장은 행별 결과다. 유효 행은 저장하고 실패 행은 원래 입력과 오류를 돌려줘 편집 내용을 유지한다. 이 동작은 전체 일괄 성공을 의미하지 않는다.
9. 마케팅 점수·HIRA 확인필요의 실제 계산 정책이 없는 값은 미확인으로 표시한다. 임의 점수를 실제 정책 값처럼 만들지 않는다. ERP·HIRA 결과는 전부 MOCK이다.

|---|---|---|---|
| H03-B-P1-01 | 병합 대표 거래처의 미완료 ERP 요청에 늦은 결과가 도착하면, 병합으로 승계한 ERP 코드가 덮어써질 수 있음 | 대표의 REQUESTING/FAILED/TIMED_OUT 요청 검사, 승인된 ERP 식별자 변경 거부, 정상 병합 회귀 | 작업자 B 독립 재현 해소 확인 |

작업자 B는 최초 고객 도메인 20건, 정책 5건 및 실제 HTTP 3개 시나리오군을 독립 실행하여 통과를 확인했다. 위 부정 재현 해소와 최종 CI·PC/390px 증거 확인 전에는 완료 승인으로 해석하지 않는다.

추가 독립 재검증 7개 군은 모두 통과했다: 미완료 ERP 병합/식별자 불변, 모든 고객 이력·멱등·감사 응답 마스킹, 숨김 필드 누출 차단, 관련 READ 없는 전환 옵션/360 차단, 수동 필드 보호 승계, HIRA 제외 true/false 승계, 미변경 필드의 후속 HIRA 갱신. 최종 승인에는 실제 CI 및 브라우저 25개 시나리오 결과가 추가로 필요하다.

## 운영 적용 잔여

실제 ERP·심평원·SQL·메일·지도 서비스에 대한 인증·payload·실접속은 이 단계에서 검증하지 않았다. 목업 가정으로 정한 소유자 변경, 기존 레코드 연결·병합, 원천명 동기화, 점수 계산의 본사 정책 확인은 운영 적용 전 별도 항목이다.

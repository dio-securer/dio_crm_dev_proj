# U03 — 일괄 편집·그룹·순서

선택 행의 표시/필수/읽기 전용을 유지·예·아니오로 검토 후 원자적으로 로컬 적용한다. 검색/그룹/필터 변경 시 선택을 해제하며 현재 결과만 전체 선택한다. 단일 그룹·검색 없음에서 드래그 및 위/아래 이동 제공. 실행 취소·재실행은 작업본 이력 50개이며 저장 성공 후 이력을 정리한다.

그룹 추가·수정·제거 시 대상 그룹으로 필드를 이동한다. 확장 필드는 정의와 배치를 함께 추가한다. 비활성화는 정의를 보존하고 규칙·목록·액션 참조가 있으면 차단한다.

검증: frontend build PASS, designer-unit 6/6 PASS(필수 불변 일괄 변경 원자성, 고아 필드 없는 그룹 이동, stable-key 순서 포함). 두 모드 UI에서 필터 선택 해제, 10행 일괄 변경·한 번에 undo/redo, name 포함 숨김 전부 취소, 확장 필드 생성/비활성화 PASS. 명령 `CHROMIUM_PATH=/tmp/ui-browser/chromium pnpm test:admin:designer-ui`.

# 새 거래처 화면 설계 사용법

적용 대상은 관리자 시연 모드의 거래처 화면 설계입니다. `/admin/fields`, `/admin/screens`, `/admin/sections`, `/admin/extension-fields`에서 시작합니다. 일반 사용자는 실제 거래처 화면을 봅니다.

## 전화번호 순서를 바꾸고 여러 필드를 읽기 전용으로 만들기
1. 왼쪽에서 전화번호가 있는 그룹을 선택합니다. 검색창에 `phone`을 입력해도 됩니다.
2. `phone` 행의 **순서**를 바꿉니다. 숫자가 작을수록 먼저 나옵니다. 검색을 지운 단일 그룹에서는 위/아래 버튼 또는 드래그로 이동할 수 있습니다.
3. 바꿀 행의 선택 상자를 체크합니다. **현재 결과 전체 선택**은 화면의 검색·그룹 조건에 맞는 행만 선택합니다. 조건을 바꾸면 선택이 해제됩니다.
4. **일괄 변경 검토**에서 읽기 전용을 **예**로 바꾸고 나머지는 **유지**로 둡니다. 적용 전에 대상 코드를 확인합니다. 필수 불변·상속 잠금에 어긋나면 전체 변경을 취소합니다.
5. **실행 취소**는 직전 일괄 작업 전체를 한 번에 되돌립니다. 저장된 초안/게시 이력을 복원하는 기능은 아닙니다.
6. **변경한 영역 전체 초안 저장**을 누릅니다. 성공한 영역과 실패한 영역이 따로 표시됩니다. 실패하면 입력을 확인하고 다시 저장합니다. 저장만으로 실제 거래처 화면은 바뀌지 않습니다.
7. 오른쪽 **화면 미리보기**에서 작업본/현재 게시본, 샘플 역할·우선순위·화면 폭을 비교합니다. 미리보기 값은 업무 데이터로 저장되지 않습니다.
8. **검증 대상 초안**을 펼쳐 다른 관리자가 만든 초안도 포함되는지 확인하고 **저장된 설정 검증**을 누릅니다.
9. **변경 검토·게시**에서 법인·게시 버전·변경 전후를 확인하고 사유를 입력해 **설정 게시**합니다. 새 변경이나 원격 버전 변경, 검증 후 10분 경과 시 다시 검증해야 합니다.
10. 일반 영업 사용자로 실제 거래처 입력 화면을 열어 게시 결과를 확인합니다.

## 상세 설정과 예외
- **상세**에서 번역 키와 표시 결과를 따로 확인합니다. 키가 없다고 번역을 자동 생성하지 않습니다. 기본값 사용을 끄면 기본값 자체가 제거됩니다. false·0·빈 문자열과 미지정은 다릅니다.
- **확장 필드 추가**는 정의와 화면 배치를 함께 만듭니다. 참조 중인 항목은 비활성화/배치 제거가 제한됩니다. 비활성화해도 정의와 기존 업무 데이터는 삭제하지 않습니다.
- 그룹을 제거할 때 해당 필드를 옮길 대상 그룹을 선택합니다.
- 사업자번호처럼 잠긴 행은 편집할 수 없습니다. 서버의 기존 권한·상속 정책도 계속 적용됩니다.
- 동시 수정 충돌이 나면 **편집 기준/내 수정/최신값**을 비교합니다. 체크한 변경만 최신값에 다시 적용한 뒤 저장·검증하세요.
- 저장 실패나 권한 오류 시 입력을 남깁니다. 권한/세션을 확인한 후 다시 조회할 때 미저장 변경을 어떻게 처리할지 선택하세요.
- 작은 화면에서는 **화면 그룹/필드 편집/화면 미리보기** 버튼으로 영역을 전환합니다. 표는 가로로 스크롤할 수 있고 저장 버튼은 하단에 있습니다.
- Tab으로 셀/버튼을 이동하고 Space로 체크박스를 바꿉니다. Enter는 셀 편집을 마치고 Escape는 포커스를 받은 셀의 원래 값으로 되돌립니다. 상세창을 닫으면 열었던 버튼으로 포커스가 돌아옵니다.
- **다른 설정**에는 메뉴·규칙·목록 보기·액션 등 기존 상세 편집 기능이 있습니다.

브라우저 목업은 같은 브라우저 저장소를 유지합니다. API 목업은 서버 프로세스 실행 중 유지되며 서버를 재시작하면 시드로 돌아옵니다. 운영 배포나 실제 ERP/OTP 연결을 의미하지 않습니다.

[공통 실행 규칙](README.md)을 먼저 읽고 원격 최신 브랜치와 선행 완료 보고서를 확인한다. 확정 요구는 상위 README 및 01~07 원문이며 이 파일은 실행 단위로 풀어 쓴 체크리스트다. 원문 요구를 삭제하거나 축소하지 않는다.

## 구현 체크리스트

- [x] multi-domain 게시, 영향 회사/필드/승인 미리보기, 예약·취소·복원, cache 갱신 및 변경 이력을 실제 관리 화면에 연결한다.
- [x] 예약 생성 시점과 실행 시점 active version을 모두 검사한다. 취소·비활성 회사·충돌 시 기존 release를 보존하고 fake clock으로 검증한다.
- [x] 메뉴·필드·승인 규칙을 한 release로 일관되게 적용한다. 진행 중 승인·알림 snapshot 및 기존 업무는 이전 정의를 유지한다.
- [x] 법인 위임 경로·권한을 UI와 서버에서 동일하게 제한하며 미등록 registry 및 잠긴 경로를 거부한다. 상위 scope/rebase, 회사 template preview/apply를 업무 runtime까지 검증한다.
- [x] DEMO SECURITY 정책의 실제 게시·활성화와 강화 시 세션/MFA 재검사를 통합한다(T43-INTEGRATION). 실제 OTP/SSO 공급자 연동은 추가하지 않는다.
- [x] rollback은 새 release를 만들며 승인·업무·sequence·보안 회수는 되돌리지 않는다. reset preview 만료·stale 검사, 대상 dataset/권한 경계와 API 세션 폐기를 검증한다.
- [x] 모바일/키보드 편집, 회사 전환 저장·폐기·취소, 저장 실패 시 입력/포커스 보존, 이전 회사 지연 응답 차단을 구현·검증한다.

필수 인수 항목: **T09,T10,T25,T26,T33,T43-INTEGRATION,T55~T59,T81,T83 (T58-INTEGRATION 포함)**. 각 기대값·모드는 06 원문을 그대로 따른다. 공통 gate와 기존 기능 회귀를 포함한다.

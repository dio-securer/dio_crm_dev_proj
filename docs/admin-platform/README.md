## 목적과 범위
본사/법인의 메뉴·화면·필드·명칭·권한·승인 흐름을 관리자가 설정하고, 현재 목업 데이터를 이용해 동작을 검증할 수 있도록 한다. 이번 변경은 문서 작성이며 애플리케이션 구현이나 DB 실행은 수행하지 않는다.

사용자 지정 범위:
- 법인·조직·사용자: ADM-01~03, 30
- 권한·보안: ADM-04~06, 13, 28
- 법인별 설정·메뉴·화면: ADM-07~12, 16~18, 34
- 명칭·언어·기준정보: ADM-14~15, 33, 37
- 프로세스·승인·알림: ADM-19~23
- ERP 및 설정 적용: ADM-24~26

“ERP ADM 26까지”는 기존 번호 체계의 ADM-24 ERP 설정, ADM-25 연계 운영, ADM-26 설정 버전·적용까지 포함하는 것으로 해석한다. ADM-26 자체는 ERP 기능 번호가 아니다.

총 31개 ADM 영역을 포함한다. ADM-27 독립 감사관리 화면, 29 첨부 정책, 31 가져오기/내보내기, 32 중복 병합, 35 출력, 36 대시보드, 38 법인 개설 도구는 별도 범위다. 단, 이번 기능의 변경·승인·배포 이력 기록은 필수 내부 기능으로 포함한다.

## 이번 구현의 목표
- DB 없는 브라우저 목업에서도 관리 설정을 저장하고 실제 화면에 적용할 수 있다.
- 같은 국가의 서로 다른 법인도 필드·메뉴·권한·승인 설정이 다르게 동작한다.
- NestJS의 목업 Repository를 사용하는 API 모드에서 서버 검증도 확인한다.
- ERP 요청 → 모의 성공/실패/지연/중복 응답 → 상태 반영/재처리를 재현한다.
- 모든 모의 연계 결과는 화면과 데이터에 MOCK 표시를 유지한다.
- 리드~납품 전체 업무 프로세스 재개발은 이번 단계의 목표가 아니다. 설정 효과를 확인할 거래처/승인 샘플/연계 샘플을 연결한다.

## 범위 결정과 적용 원칙
설정으로 제공할 수 있는 기능은 등록된 화면/액션/연산자 범위로 제한한다. 임의 SQL·JavaScript·외부 URL 실행은 제공하지 않는다. 핵심 금액 계산과 업무 트랜잭션은 개발 코드로 유지한다.

문서 내 예시 법인·결재선·통화·기한·잠금 횟수 등은 목업 검증용이며 실제 현업 확정값이 아니다. 기존 GLOBAL 승인자 미확정 사항을 실제 정책으로 확정하지 않는다.

## 검토 시 유의사항
이 문서는 기존 코드 검토와 사용자 요구사항에 기반한 설계안이다. 영상에서 확인되지 않은 업무 규칙을 확정한 문서가 아니다. 실제 업무 승인자·법인별 필수 항목·ERP payload는 후속 현업 검토에서 확정한다. 본 문서의 모의 시나리오는 그 확인 전에도 설정 기반 동작을 검증할 수 있게 하는 목적이다.

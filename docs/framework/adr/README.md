# 프레임워크 결정 기록 (ADR)

ADR 은 "무엇을 정했고 왜 그렇게 정했는지"를 한 장에 적은 글이다. 한 번 정한 것을 AI 가 다음 작업에서 뒤집지 않게 하려고 둔다.

## 쓰는 법

- 파일 하나에 결정 하나. 60줄을 넘기지 않는다.
- 칸은 다섯 개다: 상태, 맥락, 결정, 결과, 기계 검사.
- "기계 검사" 칸에는 그 결정을 실제로 막아 주는 가드 규칙(G01~G11)이나 보호 검사(P1~P5)를 적는다.
  없으면 "아직 기계 검사 없음"이라고 그대로 적는다. 없는 검사를 있는 것처럼 쓰지 않는다.
- 결정을 바꾸려면 기존 ADR 을 고치지 말고 새 ADR 을 쓰고, 기존 ADR 의 상태를 "대체됨(새 번호)"으로 바꾼다.
- 이 폴더는 보호 경로다(`scripts/guard/protected-paths.json`). 바꾸면 PR 요약의 "보호 파일 변경"에 나온다.

각 작업 종료 시 반드시 갱신

  • 해당 Work ID의 상태
  • 생성/수정 산출물 경로
  • Commit SHA 또는 PR 번호
  • Build/Test/Review 결과
  • 결정된 Business Rule
  • Spec Gap / Blocker
  • CURRENT / NEXT

프로젝트 재시작 규칙

1. 이 HTML을 연다. 2. CURRENT / NEXT / BLOCKER를 확인한다. 3. NEXT Work ID의 선행조건을 확인한다. 4. 관련 Spec/설계서를 읽는다. 5. 작업을 실행한다. 6. 테스트/리뷰 후 Git에 반영한다. 7. 마지막으로 이 HTML을 갱신한다.

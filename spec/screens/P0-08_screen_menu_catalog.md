## 3. Mobile 우선 화면
- 활동지도
- 활동계획/활동상세
- GPS IN/OUT
- 활동보고
- 직출/직퇴
- Lead/Account 기본조회
- 거래명세서 생성/파일확인

제약:
- 활동계획 다건 등록: PDF 기준 PC only.
- 패키지원장 Excel 다운로드: PC only.
- 거래명세서 모바일: 전체내역 PDF만 가능.

## 4. 공통 UX 원칙
- 상태별 버튼 노출을 Backend Rule과 동일하게 적용.
- `연동중` 동안 중복 요청 방지.
- 외부 원천 필드는 Read-only 표시.
- 승인완료/마감 후 수정불가 필드를 명확히 잠금.
- 지도화면은 위치권한/정확도 오류를 사용자에게 설명.
- 실패한 ERP 연동은 운영자에게 원인/재처리 액션 제공.
